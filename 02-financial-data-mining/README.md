# Financial Data Mining & Predictive Analysis

## Project Overview

This project applies data mining and statistical techniques to personal financial data to identify patterns, relationships, and factors associated with monthly expenses.

## Objective

The objective was to explore the structure and quality of a financial dataset, analyze relationships between numerical variables, apply Principal Component Analysis (PCA), and develop a Linear Regression model to predict monthly expenses.

## Dataset

The dataset contains **500 records and 7 variables**, including:

- Age
- Monthly Income
- Weekly Working Hours
- Monthly Expenses
- Savings Percentage
- Education Level
- Marital Status

## Data Preparation & Quality Assessment

The analysis included:

- Dataset structure and dimension analysis
- Data type validation
- Statistical summary
- Missing value analysis
- Duplicate checking
- Potential outlier assessment

The dataset contained **0 missing values and 0 duplicate records**. :contentReference[oaicite:1]{index=1} :contentReference[oaicite:2]{index=2}

## Exploratory Data Analysis

The project explored the distribution of numerical and categorical variables and analyzed relationships between financial variables.

## Analytical Methods

The project applied:

- Correlation Analysis
- Principal Component Analysis (PCA)
- Linear Regression

PCA was used to reduce dimensionality and analyze the information represented by the principal components.

## Predictive Modeling

A Linear Regression model was developed to predict **Monthly Expenses** using financial and demographic variables, including:

- Age
- Monthly Income
- Weekly Working Hours
- Savings Percentage

Model performance was evaluated using:

- MAE
- MSE
- RMSE
- R²
