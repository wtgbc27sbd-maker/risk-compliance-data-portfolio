# SQL Customer & Transaction Data Analysis

## Project Overview

This project applies SQL querying techniques to the AdventureWorks relational database to analyze customer, product, employee, and sales transaction data.

## Objective

The objective was to retrieve, filter, join, validate, and aggregate relational data to answer business-oriented questions involving customers, products, employees, orders, and sales.

## Dataset

The project uses the AdventureWorks database and works with relational tables including:

- Production.Product
- Production.ProductSubcategory
- Production.ProductCategory
- Sales.SalesOrderHeader
- Sales.SalesOrderDetail
- Sales.Customer
- Person.Person
- HumanResources.Employee
- Sales.SalesPerson

## SQL Analysis

The project includes 25 SQL queries covering:

- SELECT statements
- Column and table aliases
- WHERE filtering
- ORDER BY sorting
- TOP queries
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- NULL filtering
- COUNT
- SUM
- AVG
- MIN and MAX

## Data Validation & Exception Identification

Several queries were designed to identify records that require attention, including:

- Products with no sales records
- Employees who are not assigned as salespersons
- Customers who have never placed an order
- Relationships between customers and sales orders
- Relationships between products and order details

These queries demonstrate the use of relational logic and NULL filtering to identify exceptions and validate relationships between datasets.

## Transaction Analysis

The project also analyzes sales transaction data using aggregation functions to calculate:

- Total sales
- Average product prices
- Average order quantities
- Minimum and maximum product prices
- Earliest and latest online order dates
