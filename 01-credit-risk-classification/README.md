# Credit Risk Classification & Customer Segmentation

## Project Overview

This project applies machine learning techniques to bank customer financial and credit data to support credit-risk classification and customer segmentation.

## Objective

The objective was to analyze customer financial information, compare classification models, and identify customer profiles based on financial and credit characteristics.

## Data Preparation

The analysis included:

- Missing value analysis
- Duplicate checking
- Data type validation
- Exploratory and statistical analysis
- Correlation analysis

## Machine Learning Models

Two classification models were compared:

- Logistic Regression
- Random Forest

Model performance was evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score

## Results

Logistic Regression achieved **85.4% accuracy**.

F1 Score was also considered when evaluating model performance because of class imbalance between the target classes.

## Customer Segmentation

K-Means clustering was applied to identify customer profiles based on financial and credit characteristics.

## Risk & Compliance Relevance

This project demonstrates skills relevant to risk analytics, including financial data analysis, data quality validation, classification, customer profiling, model evaluation, and consideration of class imbalance.
